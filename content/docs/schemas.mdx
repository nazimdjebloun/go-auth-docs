# Schemas

This page documents the database tables that go-auth creates and manages. If you are using go-auth as a library, you generally do not need to interact with these directly — the library provides APIs for all operations. However, this reference is useful for debugging, monitoring, and understanding how the library stores data.

go-auth stores data in four groups:

- **Core auth tables** — `users`, `sessions`, `password_pepper_versions`. Created by the library's own schema initializer (`internal/database/migrations/core.go`).
- **Optional organization tables** — `organizations`, `organization_members`, `organization_invites`, `organization_audit_logs`. Created by the same initializer when `config.Organizations.Enable` is true (`core.go`), and left untouched when that flag is false.
- **Optional audit-log table** — `audit_logs`. Created by `internal/database/migrations/audit.go` when `config.Audit.Enabled` is true, and left untouched when that flag is false.
- **Optional admin tables** — `admin_users`, `admin_sessions`. Created by `internal/database/migrations/admin.go` when `config.Admin.Enabled` is true, and left untouched when that flag is false.

All columns use `NOT NULL` and inline defaults; there are no deferred migration files or pending SQL steps. A version column lives in `password_pepper_versions`, which keeps the pepper rollout visible even without the user table. This is an intentional design choice: it documents the lineage separately from the hash.

<Callout type="info" title="Custom tables are the application's responsibility">
  Any table not owned by go-auth — `user_profiles`, `billing`, `tokens`, `roles`, custom audit tables — belongs in the application's own schema. If go-auth is relevant to an application-owned table, document that dependency in the application repository.
</Callout>

## Core tables

### users

Row-level identity.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | No | `gen_random_uuid()` | Primary key. Never reused. |
| `email` | `text` | No | — | Lowercased, unique. |
| `password_hash` | `text` | No | — | Used only when `EnableEmailPassword` is true. Stored on registration, password change, password reset, and invite. Updated on rehash-on-login. |
| `email_verified` | `boolean` | No | `false` | Set by `POST /auth/verify-email`. Checked by `RequireEmailVerification`. |
| `provider` | `text` | No | `'email'` | Stays `'email'` for email/password users. For OAuth users, set to the provider name (e.g. `'github'`) on first OAuth login. `password_hash` is empty when this is not `'email'`. |
| `provider_id` | `text` | No | — | The provider's stable user identifier (e.g. GitHub's numeric user ID). Null/empty for email/password users. |
| `role` | `text` | No | `'user'` | `user` or `admin`. |
| `two_factor_enabled` | `boolean` | No | `false` | Enabled by default in `POST /auth/2fa/verify` for users who haven't gone through the flow yet. Disabled by default in `POST /auth/register` if `RequireEmail2FA` is off. |
| `two_factor_secret` | `text` | No | — | Used by the 2FA flow to verify TOTP codes. |
| `two_factor_code` | `text` | No | — | Ephemeral. Holds the pending 2FA login code until it is consumed by `POST /auth/2fa/verify`. |
| `two_factor_code_expires_at` | `timestamptz` | No | — | Expiry for the current `two_factor_code`. |
| `two_factor_attempts` | `integer` | No | `0` | Counts failed `POST /auth/2fa/verify` attempts before the code is expired. |
| `created_at` | `timestamptz` | No | `now()` | Set once on creation. Never updated. |
| `updated_at` | `timestamptz` | No | `now()` | Updated on every meaningful state change. |
| `password_pepper_version` | `integer` | Yes | `NULL` | Nullable. Stays `NULL` for unpeppered rows. Set to the current version on write. |
| `require_password_change` | `boolean` | No | `false` | Set by the `POST /auth/admin/reset-user-password` flow to force a password change on next login. |

**Index:** `idx_users_email` on `email` (unique).

**Index:** `idx_users_provider` on `(provider, provider_id)`. Partial: only rows where `provider != 'email'`.

**Index:** `idx_users_password_hash` on `password_hash`. Partial: only rows where `password_hash != ''`.

**Index:** `idx_users_role` on `role`.

**Migration caution:** `password_hash` and `provider`/`provider_id` are mutually exclusive by convention, not by a database constraint — the application relies on the code layer to keep them consistent. A future migration may add a conditional `NOT NULL` check; until then, only touch these columns through go-auth APIs.

**Referenced by:**
- `sessions.user_id` → `users.id`
- `password_pepper_versions.used_by` → `users.id`
- `organization_members.user_id` → `users.id`
- `organization_audit_logs.user_id` → `users.id`
- `organization_invites.invited_by` → `users.id`
- `admin_users.user_id` → `users.id` (optional relation)

### sessions

Authentication session state. One row per active session, created on login/registration/OAuth, updated on token refresh and touch, and deleted on logout, revocation, or expiry cleanup.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | No | `gen_random_uuid()` | Primary key. Never reused. |
| `user_id` | `uuid` | No | — | FK → `users.id`. On delete: CASCADE. |
| `token` | `text` | No | — | Opaque bearer token (opaque string, not a JWT). The current session token. Never reused. |
| `refresh_token` | `text` | No | — | Opaque refresh token. Rotated on every refresh; the previous value is still accepted during `GraceWindow` so two in-flight refreshes do not log the user out. |
| `user_agent` | `text` | No | — | Client identification string. Copied from the first request in the session lifecycle. |
| `ip_address` | `text` | No | — | Client IP. Recorded when `TrustedIPs` and `IPAddressHeader` are configured; otherwise the peer address. |
| `expires_at` | `timestamptz` | No | — | Absolute hard expiry (`SessionConfig.TTL`). |
| `last_active_at` | `timestamptz` | No | `now()` | Updated on every authenticated request, subject to `SessionConfig.TouchDebounce`. |
| `idle_expires_at` | `timestamptz` | No | — | Sliding idle timeout (`SessionConfig.IdleTTL`). Reset on every authenticated request. |
| `created_at` | `timestamptz` | No | `now()` | Set once on creation. Never updated. |

**Index:** `idx_sessions_user_id` on `user_id`.

**Index:** `idx_sessions_expires_at` on `expires_at`. Partial: only unexpired rows.

**Index:** `idx_sessions_token` on `token` (unique).

### password_pepper_versions

Versioned pepper key lineage. One row per pepper version actually used in production.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `version` | `integer` | No | — | Primary key. The pepper version that was active when this row was created. `NULL` means unpeppered. |
| `created_at` | `timestamptz` | No | `now()` | When this pepper version started being used. |
| `used_by` | `uuid` | Yes | `NULL` | FK → `users.id`. NULL until someone actually logs in with this pepper version, then points to that first user. Index on this column (`idx_password_pepper_versions_used_by`) is partial (`used_by IS NOT NULL`), so it stays empty until the first login. |

**Index:** `idx_password_pepper_versions_used_by` on `used_by`. Partial: only rows where `used_by IS NOT NULL`.

**Index:** `idx_password_pepper_versions_version` on `version` (unique).

## Optional tables

### organizations

Multi-tenant organization container. Only created when `config.Organizations.Enable` is true; the library never touches this table when that flag is false. One row per organization.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | No | `gen_random_uuid()` | Primary key. |
| `name` | `text` | No | — | Display name. |
| `slug` | `text` | No | — | URL-safe identifier. Unique. |
| `created_at` | `timestamptz` | No | `now()` | Set once on creation. Never updated. |
| `updated_at` | `timestamptz` | No | `now()` | Updated on every meaningful state change. |

**Index:** `idx_organizations_slug` on `slug` (unique).

### organization_members

User-to-organization membership. One row per user per organization.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | No | `gen_random_uuid()` | Primary key. |
| `organization_id` | `uuid` | No | — | FK → `organizations.id`. On delete: CASCADE. |
| `user_id` | `uuid` | No | — | FK → `users.id`. On delete: CASCADE. |
| `role` | `text` | No | — | One of: `owner`, `admin`, `member`. |
| `created_at` | `timestamptz` | No | `now()` | Set once on creation. Never updated. |
| `updated_at` | `timestamptz` | No | `now()` | Updated on every meaningful state change. |

**Index:** `idx_organization_members_org_id` on `organization_id`.

**Index:** `idx_organization_members_user_id` on `user_id`.

**Index:** `idx_organization_members_org_user` on `(organization_id, user_id)` (unique).

### organization_invites

Pending organization invitations. One row per invite.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | No | `gen_random_uuid()` | Primary key. |
| `organization_id` | `uuid` | No | — | FK → `organizations.id`. On delete: CASCADE. |
| `email` | `text` | No | — | Lowercased. |
| `role` | `text` | No | — | One of: `owner`, `admin`, `member`. |
| `invited_by` | `uuid` | No | — | FK → `users.id`. On delete: SET NULL. |
| `token` | `text` | No | — | Unique invitation token. |
| `expires_at` | `timestamptz` | No | — | Invite expiry (`OrganizationConfig.InviteTTL`). |
| `created_at` | `timestamptz` | No | `now()` | Set once on creation. Never updated. |

**Index:** `idx_organization_invites_org_id` on `organization_id`.

**Index:** `idx_organization_invites_token` on `token` (unique).

**Index:** `idx_organization_invites_email_org` on `(email, organization_id)`.

### organization_audit_logs

Organization-scoped audit events. Append-only — created on organization operations; never updated or deleted.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | No | `gen_random_uuid()` | Primary key. |
| `organization_id` | `uuid` | No | — | FK → `organizations.id`. On delete: CASCADE. |
| `actor_id` | `uuid` | Yes | `NULL` | FK → `users.id`. Null for system-generated events. |
| `action` | `text` | No | — | Event name (e.g. `member_added`, `member_removed`). |
| `details` | `jsonb` | Yes | `NULL` | Arbitrary event payload. |
| `created_at` | `timestamptz` | No | `now()` | When the event occurred. |

**Index:** `idx_organization_audit_logs_org_id` on `organization_id`.

**Index:** `idx_organization_audit_logs_actor_id` on `actor_id`. Partial: only non-null values.

**Index:** `idx_organization_audit_logs_created_at` on `created_at`.

## Audit-log table

### audit_logs

Append-only audit events. Only created when `config.Audit.Enabled` is true; the library never touches this table when that flag is false. One row per event.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | No | `gen_random_uuid()` | Primary key. |
| `user_id` | `uuid` | Yes | `NULL` | FK → `users.id`. Null for admin and unauthenticated events. |
| `action` | `text` | No | — | Event name. |
| `details` | `jsonb` | Yes | `NULL` | Arbitrary event payload. |
| `ip_address` | `text` | Yes | `NULL` | Client IP. |
| `user_agent` | `text` | Yes | `NULL` | Client identification string. |
| `created_at` | `timestamptz` | No | `now()` | When the event occurred. |

**Index:** `idx_audit_logs_user_id` on `user_id`.

**Index:** `idx_audit_logs_created_at` on `created_at`.

**Index:** `idx_audit_logs_action` on `action`.

**Index:** `idx_audit_logs_ip_address` on `ip_address`.

**Index:** `idx_audit_logs_user_action` on `(user_id, action)`.

**Index:** `idx_audit_logs_user_created` on `(user_id, created_at)`.

**Index:** `idx_audit_logs_action_created` on `(action, created_at)`.

The `details` column is freeform JSONB. Every event has `user_agent` and `ip_address` fields; some add more — login events include `method` (`password` or `oauth`) and `provider`, and registration events include `method` (`password`, `invite`, or `oauth`).

**Retention:** Optionally managed by a background cleanup job when `config.Audit.RetentionDays > 0`. Disabled by default — events are kept forever.

The audit log stores raw events, not derived data. Correlating events, computing metrics, and joining with application tables is the application's responsibility.

## Admin tables

### admin_users

Tracks which user is an admin. Only created when `config.Admin.Enabled` is true; the library never touches this table when that flag is false.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | No | `gen_random_uuid()` | Primary key. |
| `user_id` | `uuid` | No | — | FK → `users.id`. On delete: CASCADE. |
| `created_at` | `timestamptz` | No | `now()` | Set once on creation. Never updated. |

**Index:** `idx_admin_users_user_id` on `user_id` (unique).

### admin_sessions

Separate session scope for the admin surface. Only created when `config.Admin.Enabled` is true; the library never touches this table when that flag is false. One row per active admin session.

| Column | Type | Nullable | Default | Notes |
|---|---|---|---|---|
| `id` | `uuid` | No | `gen_random_uuid()` | Primary key. |
| `admin_user_id` | `uuid` | No | — | FK → `admin_users.id`. On delete: CASCADE. |
| `token` | `text` | No | — | Opaque bearer token. The current session token. |
| `refresh_token` | `text` | No | — | Rotated on refresh. |
| `user_agent` | `text` | No | — | Client identification string. Copied from the first request in the session lifecycle. |
| `ip_address` | `text` | No | — | Client IP. |
| `expires_at` | `timestamptz` | No | — | Absolute hard expiry. |
| `last_active_at` | `timestamptz` | No | `now()` | Updated on every authenticated request. |
| `idle_expires_at` | `timestamptz` | No | — | Sliding idle timeout. |
| `created_at` | `timestamptz` | No | `now()` | Set once on creation. Never updated. |

**Index:** `idx_admin_sessions_admin_user_id` on `admin_user_id`.

**Index:** `idx_admin_sessions_expires_at` on `expires_at`. Partial: only unexpired rows.

**Index:** `idx_admin_sessions_token` on `token` (unique).
