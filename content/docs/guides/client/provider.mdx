# OAuth Provider Client

This guide covers how to implement OAuth login, registration, and account linking from a frontend or mobile client.

## OAuth login

Redirect the user to the provider's authorization URL:

```javascript
// User clicks "Login with GitHub"
window.location.href = '/auth/oauth/github';
```

The library handles the OAuth flow and redirects back to your frontend with a session token.

## OAuth callback

After authorization, the provider redirects back to `/auth/oauth/github/callback`. The library exchanges the code for an access token, fetches user info, and either logs in the user or creates a new account.

The user is redirected to your frontend with either `token` or `error` in the URL.

## Account linking

Link an additional OAuth provider to the current user:

```javascript
// Redirect to provider for linking
window.location.href = '/auth/oauth/link/github';
```

Or via API:

```javascript
await fetch('/auth/oauth/link', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ provider: 'github' }),
  credentials: 'include'
});
```

## Account unlinking

Unlink an OAuth provider:

```javascript
await fetch('/auth/oauth/unlink', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ provider: 'github' }),
  credentials: 'include'
});
```

The library prevents unlinking the only authentication method.

## OAuth-only users

Users who registered via OAuth have no password. They can set one later via `POST /auth/set-password`:

```javascript
await fetch('/auth/set-password', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    token: 'set-password-token',
    password: 'new-secure-password'
  })
});
```
