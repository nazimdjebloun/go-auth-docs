# Organization Client

This guide covers how to manage organizations from a frontend or mobile client.

## Listing organizations

Get all organizations the current user belongs to:

```javascript
const response = await fetch('/auth/org', {
  credentials: 'include'
});

const data = await response.json();
data.organizations.forEach(org => {
  console.log(org.name, org.role);
});
```

## Creating an organization

Create a new organization:

```javascript
const response = await fetch('/auth/org', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: 'My Organization',
    slug: 'my-org'
  }),
  credentials: 'include'
});

const data = await response.json();
// data.organization contains the new organization
```

## Inviting members

Invite a user to an organization:

```javascript
await fetch('/auth/org/${orgId}/invite', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'invitee@example.com',
    role: 'member'
  }),
  credentials: 'include'
});
```

## Accepting invitations

Accept an organization invitation:

```javascript
await fetch('/auth/org/accept-invite', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ token: 'invite-token' }),
  credentials: 'include'
});
```

## Managing members

List members:

```javascript
const response = await fetch(`/auth/org/${orgId}/members`, {
  credentials: 'include'
});
```

Change a member's role:

```javascript
await fetch(`/auth/org/${orgId}/members/${userId}/role`, {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ role: 'admin' }),
  credentials: 'include'
});
```

Remove a member:

```javascript
await fetch(`/auth/org/${orgId}/members/${userId}`, {
  method: 'DELETE',
  credentials: 'include'
});
```
