# Client Authentication

This guide covers how to implement login, registration, and session management from a frontend or mobile client.

## Registration

Register a new user:

```javascript
const response = await fetch('/auth/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'newuser@example.com',
    password: 'secure-password'
  }),
  credentials: 'include'
});

const data = await response.json();
if (data.email_verified === false) {
  // Show email verification prompt
} else {
  // Registration successful, user is logged in
}
```

## Login

Login with email and password:

```javascript
const response = await fetch('/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'user@example.com',
    password: 'correct-password'
  }),
  credentials: 'include'
});

const data = await response.json();
if (data.pending_2fa) {
  // Show 2FA code input
  // After user enters code:
  const verifyResponse = await fetch('/auth/2fa/verify', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ code: '123456' }),
    credentials: 'include'
  });
} else {
  // Login successful
}
```

## Checking authentication status

Check if the user is authenticated:

```javascript
const response = await fetch('/auth/me', {
  credentials: 'include'
});

const data = await response.json();
if (data.active) {
  // User is authenticated
  console.log(data.user);
} else if (data.pending_2fa) {
  // User needs to complete 2FA
} else {
  // User is not authenticated
}
```

## Logout

Logout and terminate the session:

```javascript
await fetch('/auth/logout', {
  method: 'POST',
  credentials: 'include'
});
```

## Password reset

Request a password reset:

```javascript
await fetch('/auth/forgot-password', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'user@example.com' })
});
```

Reset with the code:

```javascript
await fetch('/auth/reset-password', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'user@example.com',
    code: '123456',
    password: 'new-secure-password'
  })
});
```
