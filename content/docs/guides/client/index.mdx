# Client Integration

go-auth provides an HTTP API that frontend and mobile applications can use directly. This guide covers how to integrate with the go-auth API from any HTTP client.

## Overview

The go-auth HTTP API is a standard REST API that returns JSON. It uses:

- **Session cookies** for authentication (`_session` for users, `_admin_session` for admins)
- **CSRF double-submit cookies** for state-changing requests (`_csrf`)
- **Bearer tokens** as an alternative to cookies (for API-only clients)

## Getting started

1. **Fetch a CSRF token** — `GET /auth/csrf-token`
2. **Login** — `POST /auth/login` with email and password
3. **Use the session** — Include the session cookie in subsequent requests

## CSRF protection

All state-changing requests require a CSRF token. The flow:

1. `GET /auth/csrf-token` — sets the `_csrf` cookie and returns the token value (when `ExposeCSRFTokenInBody` is true).
2. Include the token in the `X-CSRF-Token` header on state-changing requests.

For same-origin deployments, the cookie is automatically sent and readable by JavaScript. For cross-origin deployments, see [Deployment](../deployment.mdx).

## Session cookies vs bearer tokens

**Session cookies** are the recommended approach for browser-based apps:

- Automatically managed by the browser
- Secure, HttpOnly, SameSite=Lax by default
- No client-side token storage needed

**Bearer tokens** are suitable for API-only clients:

- Include the token in the `Authorization: Bearer <token>` header
- Store securely on the client
- Manage refresh manually

## 2FA flow

When 2FA is required:

1. `POST /auth/login` returns `pending_2fa: true` and a short-lived session token.
2. User receives a code by email.
3. `POST /auth/2fa/verify` with the code completes authentication.
4. `GET /auth/me` returns `active: true` when fully authenticated.

## Example: fetch API

```javascript
// Login
const response = await fetch('/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'user@example.com', password: 'password' }),
  credentials: 'include' // important: sends and receives cookies
});

const data = await response.json();
if (data.pending_2fa) {
  // Redirect to 2FA verification
} else {
  // Login successful
}

// Authenticated request
const meResponse = await fetch('/auth/me', {
  credentials: 'include'
});
const meData = await meResponse.json();
```
