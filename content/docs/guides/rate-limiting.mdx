# Rate Limiting

go-auth includes built-in rate limiting for all auth routes. It is enabled by default with sensible limits. The built-in rate limiter is not a replacement for infrastructure rate limiting — it is a defense-in-depth measure for auth endpoints only.

## Setup

Rate limiting is enabled by default. To customize it:

```go
goauth.WithRateLimit(ratelimit.Config{
    Enabled: true,
    Default: ratelimit.Rate{Requests: 60, Window: time.Minute},
    Routes: map[string]ratelimit.Rate{
        "POST /auth/login": {Requests: 10, Window: time.Minute},
        "POST /auth/register": {Requests: 5, Window: time.Minute},
    },
})
```

## Default limits

The default configuration applies sensible limits to sensitive endpoints:

| Route | Default Limit |
|---|---|
| `POST /auth/login` | 10 requests/minute |
| `POST /auth/register` | 5 requests/minute |
| `POST /auth/forgot-password` | 5 requests/minute |
| `POST /auth/reset-password` | 5 requests/minute |
| `POST /auth/verify-email` | 10 requests/minute |
| `POST /auth/resend-verification` | 3 requests/minute |
| `POST /auth/2fa/verify` | 5 requests/minute |
| `POST /auth/admin/login` | 10 requests/minute |

All other routes default to 60 requests/minute.

## Disabling rate limiting

Disable rate limiting entirely:

```go
goauth.WithRateLimitEnabled(false)
```

This logs a warning at startup — it's flagged as insecure for production.

## Disabling per-route

Disable rate limiting for a specific route:

```go
goauth.WithRateLimitRoute("POST /auth/login", ratelimit.Rate{Requests: 0})
```

## Distributed rate limiting

The default in-memory store works for single-instance deployments. For multi-instance deployments, use a distributed store:

```go
goauth.WithRateLimitStore(redisStore)
```

The store must implement the `ratelimit.Store` interface.

## IP-based rate limiting

By default, rate limiting keys by `RemoteAddr`. To key by a proxy header:

```go
goauth.WithIPAddressHeader("CF-Connecting-IP")
goauth.WithTrustedIPs([]string{"10.0.0.0/8"})
```

The header is only honored from a peer in `TrustedIPs`; otherwise it's ignored.
